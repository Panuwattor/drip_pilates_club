# สร้างคู่มือเป็นไฟล์ Word

แปลงคู่มือที่อยู่ในระบบ (Blade) ให้เป็นไฟล์ `.docx` พร้อมภาพหน้าจอ

## ต้นทาง

| เล่ม | ไฟล์ต้นทาง | ภาพ |
|---|---|---|
| แอดมิน (ไทย) | `resources/views/admin/manual/index.blade.php` | `public/docs/manual/img/` |
| ลูกค้า (ไทย/อังกฤษ) | `resources/views/customer/guide.blade.php` | `public/docs/guide/img/` |

คู่มือลูกค้าใช้ `__t('ไทย','English')` สคริปต์จึงสร้างได้ทั้งสองภาษาจากไฟล์เดียว
ส่วนคู่มือแอดมินมีเฉพาะภาษาไทย ถ้าต้องการฉบับอังกฤษต้องแปลในไฟล์ Blade ก่อน
แล้วเพิ่ม `("admin", "en")` ในลูปท้ายไฟล์ `make_all.py`

## วิธีสร้างใหม่

```bash
pip install python-docx
python tools/word-manual/make_all.py
```

ไฟล์ออกที่ `public/docs/word/`

## ไฟล์

- `parse_blade.py` — อ่าน Blade ตัด directive แทนค่า `__t()` ตามภาษา แล้วแปลง HTML เป็นบล็อก
- `build_docs.py` — เขียนบล็อกลง Word (ปก สารบัญ หัวข้อ ตาราง กล่องเน้น ภาพ เลขหน้า)
- `make_all.py` — ตัวสั่งงาน กำหนดชื่อเล่มและภาษา

## หมายเหตุ

- **สารบัญเขียนลงไปจริง** เห็นได้ทันทีที่เปิดไฟล์ ไม่ต้องกด F9 หรือ Update field
  แต่ละบรรทัดกดแล้วกระโดดไปบทนั้นได้ (ใช้ bookmark ภายในเอกสาร)
- ฟอนต์ใช้ Leelawadee UI ซึ่งมีมากับ Windows รองรับทั้งไทยและอังกฤษ
- ถ้าเพิ่มบทหรือเปลี่ยนภาพในคู่มือ ให้รันสคริปต์ใหม่ ไม่ต้องแก้ Word ด้วยมือ
- **ถ้าไฟล์เปิดค้างอยู่ใน Word จะเขียนทับไม่ได้** สคริปต์จะบอกว่าไฟล์ไหนถูกล็อก
  ให้ปิดใน Word ก่อนแล้วรันใหม่
